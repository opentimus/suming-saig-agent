## 衔接关系

```
G1 龟蛇主线
  → G2 内东湖主线【可增补：G9 光谷支线】
    → G3 外东湖主线
      → G4 武昌主线【可增补：G8 武昌支线】
        → G5 汉口主线【可增补：G7 汉口支线】
          → G6 汉阳主线
```

**规范化顺序**（脚本输出排序与行程天数顺序均以此为准，与用户传入顺序无关）：

```
G1 → G2 → G9 → G3 → G4 → G8 → G5 → G7 → G6
```

## 支线挂靠关系

| 支线 | 挂靠主线 | 增补位置 |
| --- | --- | --- |
| G9 光谷支线 | G2 内东湖主线 | 排在 G2 之后 |
| G8 武昌支线 | G4 武昌主线 | 排在 G4 之后 |
| G7 汉口支线 | G5 汉口主线 | 排在 G5 之后 |

单独点名某条支线时，若用户需要连贯行程，应一并传入其挂靠主线（如只说「光谷怎么玩」→ 传 G2 G9）。

## N 日游推导

| 天数 | 线路组合 |
| --- | --- |
| 1 日 | G1 |
| 2 日 | G1、G2 |
| 3 日 | G1、G2、G3 |
| 4 日 | G1、G2、G3、G4 |
| 5 日 | G1、G2、G3、G4、G5 |
| 6 日 | G1、G2、G3、G4、G5、G6 |
| 7 日 | G1–G6 + G9 |
| 8 日 | G1–G6 + G9、G8 |
| 9 日 | 全部 9 条（G1、G2、G9、G3、G4、G8、G5、G7、G6） |

规则：N ≤ 6 取主线前 N 条；N > 6 先取 6 条主线，再按 G9、G8、G7 顺序补足。

## 景点 → 代号速查

用于从用户提到的景点名反查其所属线路。也可用 `scripts/query_route.py --find <景点名>` 直接反查。

> 下列列表已按接口「排序」字段**递增**排列，与 `scripts/query_route.py` 的输出顺序一致。若后续后台数据调整，请以脚本实时输出为准；`G4` 缺 5 号、`G8` 的宝通寺与粮道街同为 1 号，均属源数据情况。

- **G1 龟蛇主线**：祁万顺、龟山公园、晴川阁、蟹神咩咩、长江大桥、辛亥革命博物院、山顶烧烤·又见黄鹤楼、夜上黄鹤楼、斗级营、中华路城市阳台
- **G2 内东湖主线**：广八路、凌波门栈道、省博物馆、湖北美术馆、30PARK、东湖听涛景区、东湖绿道、东湖磨山景区、风光村一棵树、永红串串香、光谷步行街
- **G3 外东湖主线**：刘聋子牛肉粉、东湖吹笛景区、翠蝈蝈的饭馆、东湖鼓架山景区、东湖落雁景区、武汉城市学院侧街、欢乐谷
- **G4 武昌主线**：湖南老宝庆牛肉面馆、四美塘文化公园、月亮湾城市阳台、元宝纸上烤鱼、月亮湾江滩、沙湖公园、肥肥虾庄、楚河汉街
- **G5 汉口主线**：周记牛肉面、武汉民众乐园、汉口水塔美食街、江汉路步行街、江汉关博物馆、笨罗卜湖南菜、汉口江滩、知音号两江夜游
- **G6 汉阳主线**：刘记三狗牛肉面馆、多福路跨江步行桥、月湖风景区、汉阳造、归元寺、无敌锤子老火锅、南岸嘴江滩公园
- **G7 汉口支线**：兰陵路、黎黄陂路步行街、巴公房子、咸安坊、TSUTAYA　BOOKSTORE（茑屋）、夏氏砂锅、花园道、吉庆民俗街
- **G8 武昌支线**：宝通寺、粮道街、武商梦时代、武汉大学、昙华林
- **G9 光谷支线**：华中科技大学、光谷空轨、中国建筑科技馆、湖北人形机器人创新中心

> 注意：景点与线路的归属以接口数据为准。例如「光谷步行街」归属 G2 内东湖主线，而「光谷空轨」归属 G9 光谷支线，二者不同。
